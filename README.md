# Ilha Dinâmica

App Android no estilo da Dynamic Island do iPhone, posicionado sobre a câmera frontal.

## Etapas
1. **Base** — permissões e ilha parada sobre a câmera, com ajuste fino *(atual)*
2. Música (compacta, expandida, controles)
3. Notificações e carregamento
4. Chamada, timer e divisão com bolinha
5. Polimento: tela cheia, configurações, filtros por app

## Instalar
Baixe o `IlhaDinamica.apk` mais recente em **Releases**. Cada envio para `main` gera um APK novo.
